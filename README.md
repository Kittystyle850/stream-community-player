# 🎬 Stream Community Player

> Player stile Netflix per **StreamingCommunity** e **VixCloud**: fullscreen automatico, audio, autoplay, risoluzioni reali, UI moderna.

[![Firefox](https://img.shields.io/badge/Firefox-121%2B-orange?logo=firefox)](https://addons.mozilla.org/firefox/addon/stream-community-player/)
[![Chrome](https://img.shields.io/badge/Chrome-110%2B-blue?logo=googlechrome)](https://www.google.com/chrome/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

---

## ✨ Funzionalità

- 🖥️ **Fullscreen automatico** — Entra in fullscreen appena parte il video
- 🔊 **Audio automatico** — Attiva l'audio senza click
- ⏭️ **Prossimo episodio automatico** — Passa senza ricaricare la pagina
- 🎞️ **Selezione risoluzione reale** — Tutte le risoluzioni del manifest
- ⏯️ **Ripresa automatica** — Ricomincia dall'ultima posizione
- 🎨 **UI moderna** — Controlli stile Netflix
- ⌨️ **Scorciatoie tastiera** — Spazio, frecce, F, M, R, N

---

## 📦 Installazione

### Firefox (automatica)

👉 [Installa da Firefox AMO](https://addons.mozilla.org/firefox/addon/stream-community-player/)

### Brave / Chrome / Edge (manuale)

1. Vai su [Releases](https://github.com/Kittystyle850/stream-community-player/releases)
2. Scarica l'ultimo `stream-community-player.zip`
3. Estrai in una cartella
4. Apri `brave://extensions` o `chrome://extensions`
5. Attiva **Modalità sviluppatore**
6. Clicca **Carica estensione non pacchettizzata**
7. Seleziona la cartella

## ⌨️ Scorciatoie

| Tasto | Azione |
|---|---|
| `Spazio` | Play/Pausa |
| `←` `→` | Salta ±5s |
| `↑` `↓` | Volume ±10% |
| `F` | Fullscreen |
| `M` | Muto |
| `R` | Ricomincia |
| `N` | Prossimo episodio |
