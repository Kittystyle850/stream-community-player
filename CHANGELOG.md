# Changelog

Tutte le modifiche importanti sono documentate qui.

## [1.0.0] - 2025-01-01

### Added
- Rilascio iniziale
- Fullscreen automatico (element + jwplayer API)
- Audio automatico tramite contentSettings policy
- Autoplay prossimo episodio (SPA swap)
- Ripresa automatica della posizione
- Pannello impostazioni integrato
- Scorciatoie tastiera (Spazio, frecce, F, M, R, N)
- UI moderna stile Netflix
- Compatibilità Firefox 121+ e Chrome 110+
